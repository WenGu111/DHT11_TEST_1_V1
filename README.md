# DHT11_TEST_1_V1

北京交通大学 电子信息工程学院 大学生创新活动中心 —— 实验一：DHT11 温湿度传感器

## 功能

- 读取 DHT11 温湿度，通过串口输出（输出数据前带本组组号：**3**）
- 将温度变化转换为 LED 闪烁：温度上升闪烁变快，温度下降闪烁变慢

## 接线

| DHT11 | UNO |
|-------|-----|
| VCC   | 5V  |
| GND   | GND |
| S     | 数字引脚 2 |

- LED 使用 UNO 板载 13 脚
- 若使用 4 脚裸传感器，需在 S 与 VCC 之间接 10kΩ 上拉电阻

## 使用

1. 安装库：DHT sensor library（`实验准备.zip` 中的 DHT-sensor-library-master.zip）
2. 用 Arduino IDE 打开 `DHT11_TEST_1_V1.ino`
3. 选择开发板 Arduino Uno 和对应端口，点击上传
4. 打开串口监视器，波特率选 **9600**

串口输出示例：

```
组号: 3  温度: 21.50 C   湿度: 34.20 %
```
