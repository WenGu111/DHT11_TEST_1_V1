# 实验二：DS1307 时钟与 TM1637 数码管

北京交通大学 电子信息工程学院 大学生创新活动中心

## 功能

- 读取 DS1307 实时时钟时间并通过串口输出（输出数据前带本组组号：**3**）
- TM1637 数码管显示 **"组号:分钟"**：前两位组号（不足两位补 0），后两位分钟，中间冒号常亮

## 接线

| DS1307 | UNO |
|--------|-----|
| VCC    | 5V  |
| GND    | GND |
| SDA    | A4  |
| SCL    | A5  |

| TM1637 | UNO |
|--------|-----|
| VCC    | 5V  |
| GND    | GND |
| CLK    | 10  |
| DIO    | 9   |

## 使用

1. 安装库：RTClib（RTClib-master.zip）、TM1637（TM1637.zip）
2. 用 Arduino IDE 打开 `RTCtester.ino`
3. 选择开发板 Arduino Uno 和对应端口，点击上传
4. 打开串口监视器，波特率选 **9600**

串口输出示例：

```
组号: 3  时间: 15:34:56
```
